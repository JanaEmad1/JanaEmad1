## Hi, I'm Jana 👋

AI Engineer building applied AI across **LLMs / NLP**, **computer vision** and **optimisation**.
Each project comes with measured results, honest limitations and the business case it serves.

### LLM assistants

**[FinPilot](https://github.com/JanaEmad1/finpilot)**: an LLM banking assistant with a statistically evaluated
release process. Intent model vs. DistilBERT decided by a significance test, safe SQL tools, PII redaction, CI release gate.
**Impact:** 84.5% of customer messages answered automatically at 97.3% accuracy. The rest go to a human.
`LLM` `Gemini` `scikit-learn` `FastAPI` `A/B testing`

**[WhatsApp Clinic Assistant](https://github.com/JanaEmad1/whatsapp-clinic-assistant)**: a Gulf-Arabic / English
WhatsApp receptionist that answers only from the clinic's own information, books appointments and hands off to staff.
**Impact:** 98.5% of messages routed correctly with **0 wrong answers** in evaluation, and after-hours enquiries answered instantly.
`RAG` `Arabic NLP` `Twilio / Meta API` `FastAPI`

**[Distill](https://github.com/JanaEmad1/DISTILL)**: a Flutter app that summarises PDF/DOCX/TXT documents with Gemini and
lets you chat with them. Riverpod, Firebase, 60 tests, and an offline demo mode.
**Impact:** a 15-minute read becomes a 1.5-minute summary plus follow-up questions.
`Flutter` `Firebase` `Gemini`

### Computer vision

**[Video Violence Detection + Crowd Analytics](https://github.com/JanaEmad1/video-violence-crowd-analytics)**:
MobileNet + Bi-LSTM flags violent CCTV clips (79.3% held-out accuracy). YOLOv8 counts people and rates crowd density.
**Impact:** focuses control-room attention, and the README shows why the false-alarm rate, not accuracy, decides the cost.
`TensorFlow` `YOLOv8` `OpenCV`

**[Traffic Sign Detection & Recognition](https://github.com/JanaEmad1/traffic-sign-detection)**: HSV segmentation,
morphology and contours find signs. HOG + SVM recognises 43 classes (79.2% on 12,630 test images).
**Impact:** automates road-sign inventory surveys, and runs on a CPU.
`OpenCV` `scikit-image` `scikit-learn`
